# Chasse aux erreurs

Le code suivant contient 10 erreurs (structure, syntaxe ou mauvaises pratiques). Recopiez-le dans un fichier `erreurs.html`, repérez les erreurs, puis corrigez-les.

```html
<html>
<head>
    <title>Mon club</title>
</head>
<body>
    <h1>Club informatique</h2>
    <p>Bienvenue au club <strong>informatique.</p></strong>
    <h3>Nos activités</h3>
    <p class=intro>Chaque mercredi, nous nous retrouvons.
    <img src="images/club.jpg">
    <a>Contactez-nous</a> href="contact.html"
</body>
</html>
```

Notez chaque erreur trouvée sous forme de commentaire HTML au-dessus de la ligne concernée, puis écrivez la version corrigée.
