# Lire du HTML

Voici trois lignes de code :

```html
<a href="contact.html" class="bouton" id="lien-contact">Nous écrire</a>
<img src="images/logo.png" alt="Logo du club">
<p class="intro">Bienvenue au <strong>club informatique</strong>.</p>
```

Questions

1. Pour chaque ligne, indiquez : le nom de la balise, son contenu et la liste de ses attributs (nom et valeur).
2. Lequel de ces éléments est un élément vide ? Comment le reconnaît-on ?
3. Quel élément est imbriqué dans un autre ? Représentez la troisième ligne sous forme d'arbre.
4. Parmi les attributs rencontrés, lequel identifie un élément de manière unique ? Lequel permet de regrouper plusieurs éléments ?
