# Ma première page

Créez un fichier `premiere-page.html` sans copier-coller (écrivez le code vous-même, de mémoire si possible) contenant :
- la structure minimale d'une page HTML5 (déclaration du type de document, langue française, encodage UTF-8) ;
- un titre de page *«Ma première page»* (visible dans l'onglet du navigateur) ;
- un titre principal *«Bonjour le web»* ;
- un paragraphe qui vous présente en une ou deux phrases ;
- un commentaire HTML décrivant le rôle du fichier.

Enfin, vérifiez votre travail :
- L'onglet du navigateur affiche-t-il le bon titre ?
- Mettez le paragraphe en commentaire, rafraîchissez : que se passe-t-il ? Retirez le commentaire.
